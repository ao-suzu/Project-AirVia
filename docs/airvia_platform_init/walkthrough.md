# Project-AirVia 構築・修正確認 (Walkthrough)

## 1. 構築成果の概要
Windowsのモバイルホットスポット機能をコアモジュールとして抽出し、インターネット接続がない環境でもPCをアクセスポイント兼サーバーとして運用できるオフラインプラットフォーム「**Project-AirVia**」を構築しました。

## 2. デザインシステムとテーマ構成（全4種・プルダウン統合UI）

### ① 1箇所に集約されたプルダウンテーマセレクタ
管理画面ヘッダー右上のテーマ選択を、複数ボタンや並列配置から **1箇所のすっきりしたプルダウンメニュー（ドロップダウン）** に統一しました。絵文字を排除したミニマルかつクリーンなタイポグラフィで構成されています。
- **ライトモード**: Cherry / Simple
- **ダークモード**: Midnight / Forest

### ② 各テーマの仕様
- **ライトモード**:
  - **Cherry**: ソフトピンク (`#F2C7C7`) / ホワイト (`#FFFFFF`) / 淡緑 (`#D5F3D8`) / 桜色アクセント (`#FFB7C5`)
  - **Simple**: チャコール黒 (`#4A4A4A`) / クールグレー (`#CBCBCB`) / ソフトアイボリー (`#FFFFE3`) / スレートブルー (`#6D8196`)
- **ダークモード**:
  - **Midnight**: ディープネイビー (`#0B0F1A`) / カード (`#111A2E`) / サブ (`#1B2A41`) / 境界 (`#2F3E56`) / ライトグレー (`#C8D3E0`)
  - **Forest** (オブシディアンティール): 最暗部ティール (`#071014`) / カード (`#0A1F24`) / サブ (`#0F3A3F`) / 境界 (`#1C6B6A`) / ミント (`#B8F2E6`)

### ③ テーマの記憶とポータル連動
- テーマの選択状態は端末の `localStorage` に保持されます。
- 参加者用ポータル（`public/portal/index.html`）にも自動連動します。

## 3. 実装されたモジュールと機能
- `src/core/hotspot.js`: ホットスポット起動・停止・SSID/PW設定（共通PowerShellビルダーで重複排除・簡潔化）
- `src/core/network.js`: ホットスポットIP固定（192.168.137.1）およびQRコード生成
- `src/server.js`: メインサーバー、シャットダウンAPI (`/exit`)、ポータル・管理API配信
- `public/admin/`: 親機管理ダッシュボード（プルダウンテーマ選択、ホットスポット3点メニュー、独立ポータル確認、アプリ一覧、終了機能）
- `public/portal/`: 参加者用ポータル（M3/HIGクリーンUI、4テーマ自動連動、終了ボタン）
- `apps/photos/`: 写真共有機能（複数アップロード、リアルタイムギャラリー、保存、動的戻り先）
- `apps/bingo/`: BINGOアプリ統合（親機ルーレット、レスポンシブチェッカー、共通ハンドラ構成、ドラムロール音源対応）
- `start.bat`: Windows用起動バッチ（文字化け防止のため英語記述）
