# Project-AirVia

Windowsのモバイルホットスポット機能を活用した、オフライン対応ローカルWi-Fi＆Webアプリケーション運用プラットフォームです。

## 特徴
- **インターネット接続不要**: Windows PCが即席のアクセスポイント＆サーバーになります。
- **QRコードで一発接続**: 管理画面に表示されるQRコードをスマホの標準カメラで読み取るだけでWi-Fiに接続できます。
- **お役立ちアプリ搭載**:
  - **AirVia Photos**: イベントや集まりで、参加者同士が写真をアップロード・閲覧・保存できる写真共有アプリ。
  - **BINGO**: ルーレット抽選親機画面と、参加者用ビンゴチェッカー画面を標準搭載。
- **プラグイン・モジュール構造**: 独自のWebアプリケーションを `apps/` フォルダに追加してポータルから簡単に配信できます。

## 起動方法
1. `start.bat` をダブルクリック（またはコマンドプロンプトで `npm start`）
2. 親機管理画面 (`http://localhost:3000/admin`) が自動で開きます。
3. 画面に表示されるWi-Fi接続QRコードとポータルアクセスQRコードを参加者に提示します。

## ディレクトリ構成
```
Project-AirVia/
├── apps/               # 搭載アプリケーション
│   ├── bingo/          # BINGOアプリ
│   └── photos/         # 写真共有アプリ
├── public/             # 静的配信アセット
│   ├── admin/          # 親機PC用ダッシュボード
│   └── portal/         # 参加者スマホ用ポータル画面
├── src/                # コアシステム
│   ├── core/
│   │   ├── hotspot.js  # モバイルホットスポット制御
│   │   └── network.js  # ネットワーク・QRコード生成
│   └── server.js       # メインExpressサーバー
├── uploads/            # アップロードされた写真などの保存先
└── start.bat           # 起動スクリプト
```
